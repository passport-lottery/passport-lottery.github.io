# Паспорт как лотерея жизни — сайт проекта

Статический сайт: чистые HTML, CSS и JavaScript, без сборки. Открывается двойным кликом по `index.html`. При первом открытии нужен интернет: шрифты Google и библиотека перелистывания StPageFlip грузятся из сети. Без интернета сайт тоже работает, но со стандартными шрифтами и без перелистывания пальцем за уголок.

```
site/
├── index.html        каркас страницы и мета-теги
├── favicon.svg       значок вкладки
├── css/style.css     оформление
├── js/data.js        ВЕСЬ контент — правим здесь
├── js/passport.js    паспорт: открытие обложки и листание
├── js/lottery.js     лотерея «Родиться заново»
├── js/main.js        сборка разделов, ссылки «к паспорту»
└── assets/
    ├── img/          картинки (og.jpg — превью ссылки)
    └── audio/        фрагменты интервью — только с разрешения собеседника
```

## Как править тексты

Все тексты лежат в `js/data.js`. Открыть в любом редакторе (VS Code, Блокнот), поправить текст в кавычках, сохранить и обновить страницу в браузере.

- Текст в одинарных кавычках `'...'`. Если внутри нужен апостроф, ставьте `\'`. Кавычки-«ёлочки» можно ставить как есть.
- После каждого объекта `{ ... }` в списке стоит запятая.
- Внутри текстов разделов можно использовать `<b>жирный</b>`, `<i>курсив</i>` и `<a href="https://...">ссылку</a>`.

Если после правки страница пустая, скорее всего, пропущена кавычка или запятая. Нажмите F12 → вкладка Console: там будет номер строки с ошибкой.

### Добавить или поменять раздел

Раздел — объект в массиве `SECTIONS`:

```js
{ id: 'medicine', title: 'Медицина', stamp: 'MEDICUS', color: '#a3322a',
  teaser: '1–2 предложения для страницы паспорта.',
  body: [
    'Первый абзац полного текста.',
    'Второй абзац.'
  ] },
```

Раздел сам появится в содержании паспорта (штамп), на своей странице паспорта и полным текстом ниже. Порядок в массиве — порядок на сайте. `id` пишется латиницей без пробелов.

Кроме абзацев, в `body` можно ставить готовые блоки (полный список — в комментарии над `SECTIONS` в `data.js`):

```js
{ lead: 'Крупный вводный абзац.' },
{ h: 'Подзаголовок' },
{ list: ['пункт', 'пункт'] },            // { olist: [...] } — нумерованный
{ facts: [['2001', 'подпись к цифре']], note: 'Источник: …' },
{ quote: 'Дословная цитата.', who: 'Должность, учреждение' },
{ gallery: [{ src: 'assets/img/docs/…webp', caption: 'Подпись' }] },
{ note: 'Мелкая приписка или источник.' }
```

Тексты страниц паспорта (`teaser`) держите короткими, до ~90 знаков: иначе на маленьких телефонах они не поместятся на страницу.

### Интервью

Массив `INTERVIEWS`. Фамилии сотрудников не пишем, только должность и учреждение. Каждая выдержка — пара «вопрос — ответ» в `excerpts`, главная цитата — в `quote`.

Аудио: положите mp3 в `assets/audio/` и впишите путь в `audio`, например `'assets/audio/zanyatost.mp3'`. **Только если собеседник разрешил публикацию.** Без разрешения оставляйте `audio: null`.

### Лотерея

`COUNTRIES` — страны и рейтинги, `RATINGS` — названия рейтингов и дата сбора данных. **Перед защитой сверить цифры:** рейтинги обновляются несколько раз в год. Все страны берутся из одного выпуска каждого рейтинга; после сверки обновите `collected`. Сравнения с ПМР на сайте нет и не должно быть.

### Картинки из Нано Бананы

Сохраните картинки в `assets/img/` в формате webp (до ~300 КБ каждая) и впишите пути в `SITE.textures` в `data.js`:

```js
textures: {
  cover: 'assets/img/cover-leather.webp',      // кожа обложки, без надписей
  emboss: 'assets/img/cover-emboss.webp',      // золотая рамка/гильош на прозрачном фоне
  paper: 'assets/img/paper.webp',              // бесшовная бумага страниц
  visaStamps: ['assets/img/visa-1.webp', 'assets/img/visa-2.webp']   // визовые штампы
}
```

Пока поле `null`, используется вариант, нарисованный кодом.

### Фото владельцев

Положите совместное фото (портрет 3:4) в `assets/img/holders.webp` и впишите `photo: 'assets/img/holders.webp'` в `SITE.holders`.

## Как выложить сайт

**Netlify (проще всего):** зайти на app.netlify.com/drop и перетащить папку `site`. Через минуту будет ссылка.

**GitHub Pages:** создать репозиторий (например, `passport-lottery`), загрузить содержимое папки `site`, затем Settings → Pages → Source: ветка `main`, папка `/ (root)`. Адрес: `https://<ник>.github.io/passport-lottery/`.

После публикации в `index.html` замените адрес превью на полный, иначе Telegram не покажет картинку:

```html
<meta property="og:image" content="https://<ваш-адрес>/assets/img/og.jpg">
<meta property="og:url" content="https://<ваш-адрес>/">
```

QR-код для слайда защиты делается по готовой ссылке в любом генераторе QR (сохранить PNG в высоком разрешении).

## Перед защитой

- Открыть сайт по QR с телефона (Android и iPhone): обложка открывается прокруткой, страницы листаются свайпом и за уголок, вертикальная прокрутка не ломается.
- Сверить рейтинги лотереи.
- Проверить, что у всех аудио есть разрешение собеседника.
